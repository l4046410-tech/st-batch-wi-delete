# 世界书批量删除 · SillyTavern 扩展

> **v2.2.0** — 用酒馆原生的折叠面板样式（右侧圆形箭头），删整本世界书只要勾选 + 一次点击，删之前自动打包备份。

给 SillyTavern 用的世界书清理工具。解决的是这个场景：**积了几十上百本世界书，一本本点开删，删到手酸**。

---

## 两个功能

| 功能区 | 做什么 | 不做什么 |
|---|---|---|
| ① 删除整本世界书 | 勾一本或多本 → 一键删掉整个书文件 | 不改动没勾选的书 |
| ② 只删除书里的某些条目 | 在书内部挑条目删（空条目 / 已禁用 / 重复内容有快捷按钮） | 书本身保留 |

两种操作**都会在删除前先下载一份备份 JSON**。

---

## 安装

1. 把整个文件夹放到：

```
SillyTavern/public/scripts/extensions/third-party/st-batch-wi-delete/
```

目录里必须有：`manifest.json`、`index.js`、`style.css`。

2. 打开酒馆 → 顶部 **扩展**（拼图图标）→ 找到「世界书批量删除」，确认已启用。
3. 按 **Ctrl + F5** 硬刷新页面。

面板出现在 **扩展设置** 区域的最下方，标题是「世界书批量删除」。看不到就往扩展设置里滚到底。

---

## 用法 ①：删除整本世界书

1. 面板里列出全部世界书，每行带 **条目数徽标**
2. 顶部可以**按名称筛选**（书多了很有用），右边「刷新」重新读取服务端列表
3. 勾选要删的书，或用「全选 / 清空」批量勾
4. 点 **「删除选中的世界书」**

执行顺序是：**确认 → 打包下载备份 → 逐本删除 → 报告结果**

想清空全部：点 **「删除全部世界书」**，弹窗里必须手动输入 `全部删除` 四个字才会执行——防止手滑。

删除完成后底部状态栏会显示类似：

```
删除完成：成功 71 本，失败 0 本（备份已下载）
```

有失败的书会单独列出来，不会静默跳过。

---

## 用法 ②：只删书里的某些条目（不删书）

展开第二个折叠区：

- **搜索**：按条目名称 / 触发词 / 内容搜
- **快捷选择**：`空条目`、`已禁用`、`重复内容`、`全不选`、`反选`
- 勾完点 **「删除选中条目」**

删条目走的是 `saveWorldInfo` / `edit` 接口，**书文件保留**，只改内容。删之前同样下载备份（`条目备份_书名_时间.json`）。

## 备份与恢复

**备份长什么样**

一次删除只下载**一个**文件，文件名：

```
世界书备份_3本_2026-11-23T14-31-05-123Z.json
```

内容是 `{ "书名": { ...完整世界书数据... }, ... }`。

> 为什么不一次下多个文件：浏览器会拦截连续多个下载，只放行第一个。所以合成一个。

**怎么恢复**

- 方式一（推荐）：World Info 面板 → **Import** → 选中那个 JSON → 逐本导入
- 方式二：用编辑器打开 JSON，把里面某一本的对象单独存成 `data/<你的用户名>/worlds/<书名>.json`
- 方式三（批量塞回）：写个脚本遍历 JSON 的 key，逐个写到上面那个 worlds 目录，重启酒馆

建议恢复前先备份现有的 worlds 目录，别在同一层覆盖错。

## 折叠与状态记忆

面板用**酒馆原生的折叠组件**（`inline-drawer`），箭头是右侧的圆形 chevron，和酒馆其他设置面板一致：

```
世界书批量删除                                    ⌄   ← 点这一行折叠整个面板
  ① 删除整本世界书                                ▾
  ② 只删除书里的某些条目（不删书）                  ▸
```

折叠状态记在浏览器 localStorage：

| key | 控制什么 |
|---|---|
| `bwd_open_root` | 整个面板 |
| `bwd_open_books` | ① 删整本 |
| `bwd_open_entries` | ② 删条目 |

刷新、关掉浏览器再开，都是你上次的样子。

## 接口与兼容

扩展优先用酒馆自己的函数，拿不到才退回 HTTP 接口：

| 动作 | 首选（酒馆内部函数） | 退回（HTTP） |
|---|---|---|
| 列世界书 | `world-info.js` 的 `world_names` / `getWorldInfoList()` | `POST /api/worldinfo/list` → 读页面下拉框 |
| 读一本 | `loadWorldInfo()` / `loadWorldInfoData()` | `POST /api/worldinfo/get` |
| 删整本 | `deleteWorldInfo()` | `POST /api/worldinfo/delete` |
| 写回条目 | `saveWorldInfo()` | `POST /api/worldinfo/edit` |

**关于 CSRF**：请求头优先从 `script.js` 导入的 `getRequestHeaders()` 取，取不到再退回 `window.getRequestHeaders`，最后读页面的 csrf meta。

没有 `X-CSRF-Token` 的 POST 会被服务端 **403** —— 这正是 v1.1 里「71 本书全部读取失败」的原因，v2.0 已修。

## 常见问题

**面板不出现**
检查三步：文件夹路径对不对（必须是 `third-party/` 下面）→ 扩展列表里有没有启用 → Ctrl+F5 硬刷新。

**所有书都显示「读取失败」**
十有八九是 CSRF token 没带上（403）。打开浏览器控制台，看有没有 `[batch-wi]` 开头的日志，里面有真实原因。如果酒馆版本改过 `getRequestHeaders` 的导出方式，把控制台报错发出来即可定位。

**删了书之后角色卡报错**
那张卡绑定了已删除的世界书。刷新酒馆一般会自动清空这个绑定；没清空就手动进角色卡把世界书那一栏改掉。

**手机上按钮挤成一列**
v2.2 已修窄屏布局。如果还挤，是酒馆主题的 `.menu_button` 有额外 `width` 覆盖，可以在浏览器里检查该元素的宽度设置。

**能删系统内置的书吗**
能。它调的是酒馆自己的删除函数，和你在世界书面板里手动删没有区别，所以删之前一定确认备份 downloads 到手了。

## 已知限制

- 一次删几百本会连续发几百个请求：慢，但会一本一本报告结果，不会中途放弃
- 备份走浏览器下载，落在你的下载目录，不会上传到任何地方（扩展本身不发外部请求）
- 只处理**世界书**，不碰角色卡、预设、聊天记录
